# Dependency security verification boundaries

`npm run test:dependency-security` enforces the existing production dependency policy: `npm audit --omit=dev --json`, zero high/critical findings. No threshold, advisory exception or audit suppression was added.

On 2026-10-06 the typography plugin was moved from admin runtime dependencies to devDependencies. Source usage is only `apps/admin/tailwind.config.js`; it generates CSS during the Vite build. Tailwind itself was already a devDependency, but the plugin's runtime peer edge classified the Tailwind/watch/glob chain as production. Lock regeneration changed dependency flags only: no package versions, integrity values, additions or removals changed. At that checkpoint the production audit returned zero findings. The admin TypeScript/Vite production build passes and generated CSS retains `.prose` typography rules.

This is a packaging classification repair, not a vulnerability patch. Full `npm audit` still reports twelve findings: eight high and four moderate, including the existing Tailwind3/watch/router build-tool chain. Build and development environments must remain separately assessed; a clean runtime audit does not certify build-tool security. Previously applied compatible URI/YAML/Humanfs patches and their causal regressions remain separate evidence. No major Tailwind migration was applied.

Production deployment/auth, scanner/private storage/email delivery, owner authoring/publish and frontend domain acceptance are independent release gates. A passing dependency source check cannot replace them.

Lock comparison retained only that package version/integrity change plus the deliberate AJV dev-to-runtime classification for server component-schema validation. Actual indexed-map oversized offsets reject before allocation; ordinary mappings and SourceNode round trips pass in `test:dependency-patches`. Production policy passes with zero high/critical; two low findings remain in KaTeX0.16.22/Plate math. The reported KaTeX fix0.18.2 is outside the parent0.16 range and has not been silently installed or certified.
